# Lokesh Sawai – Portfolio
Next.js 14 · TypeScript · Tailwind CSS · Lucide

## Run locally
1. Install Node.js 18.17+ from nodejs.org
2. `npm install`
3. `npm run dev` then open http://localhost:3000

## Edit content
Everything lives in `lib/content.ts`. Replace each PLACEHOLDER (photo, LinkedIn, GitHub, projects, experience). To update the resume, replace `public/resume.pdf`.

## Deploy on Vercel
1. Push this folder to a GitHub repository.
2. Sign in at vercel.com, click Add New > Project, import the repo.
3. Keep the defaults (Next.js is detected) and click Deploy. Every `git push` redeploys.
